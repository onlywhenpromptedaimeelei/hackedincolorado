# hackedincolorado

This repository contains reports and forensic data related to the AdrianMC investigation.

## Archive contents

- `AdrianMC_Case_Archive_FULL_0423.zip` – the entire case archive including evidence dumps and logs collected in April 2023.
- `AdrianMC_Case_Archive_SIM_Google_Network.zip` – SIM card information and Google network traces.
- `AdrianMC_Case_Archive_SIM_Google_Network (1).zip` – duplicate of the previous archive, kept for reference.

Only the compressed archives are checked into Git. Extract them to a location outside the repository to inspect the data and avoid committing bulky files.
