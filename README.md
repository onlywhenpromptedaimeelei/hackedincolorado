# Hacked in Colorado Repository

This repository collects files related to the forensic analysis of a mobile device and associated accounts used by **AdrianMC**. The materials appear to document a suspected SIM hijacking incident, suspicious network activity, and detailed device examinations. 

## Contents

The repository includes a variety of files:

- **PDF documents** summarizing the case, official letters, and detailed reports.
- **CSV spreadsheets** showing network findings, intrusion events, rational sequence mappings, and other analysis results.
- **Bug reports** captured from the device (`bugreport-fogo_g-*.txt`).
- **Android log files** such as security audits, immunization logs, and removal logs (`android_security_audit_*.log`, `android_security_removal_*.log`, etc.).
- **SSH debug logs** (`ssh_debug_*.log`).
- **Miscellaneous logs and text files** like `threat_list.txt` and `device_intrusion_report.md`.

Some archives (`*.zip`) contain collections of the above items, likely for ease of transfer or offline storage.

## Personal Data Warning

The logs and reports may contain personal or sensitive information such as account names, network locations, and timestamps. Handle these files carefully and avoid sharing them publicly.
